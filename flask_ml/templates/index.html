Data MongoDB Live

Langsung terhubung ke database MongoDB monitoring_harga_pangan. Data selalu segar dari koleksi price_histories.

📈

Prediksi Time Series

Holt-Winters Exponential Smoothing menangkap trend jangka panjang dan pola musiman mingguan harga pangan.

🎯

Akurasi Terukur

Metrik MAPE, MAE, RMSE dari validasi walk-forward 80/20. Hasil prediksi di-cache di koleksi predictions.

💡

Rekomendasi Pintar

Scoring otomatis berdasarkan tren, volatilitas, dan selisih harga untuk saran beli/tunda yang transparan.

🔐

Autentikasi User

Login & registrasi berbasis MongoDB users. Role admin dan user dengan hak akses berbeda.

📋

Riwayat Simulasi

Setiap simulasi user tersimpan di koleksi simulations untuk analisis perilaku pembelian.
